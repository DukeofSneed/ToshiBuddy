# Growing paperwork stack

- One saved counter, `sheets`, goes up on each finished desk session (`desk-done`).
- Each sheet is a desk prop with `showAfter`, so the stack grows by one per session (up
  to nine) and is still there after a restart.
- At sheets 3, 6 and 9 he says one line with the count.
- Not used: stamping (not available), sounds at the desk.
